# libazahar-py v1.0.0

A headless, scriptable host for Azahar's 3DS libretro core on macOS, with a Python layer, for testing homebrew. This is
the first release. From 1.0.0 it follows semantic versioning: until 2.0, the Python API, the C functions in
`host/azhost.h`, the `azhost` command line and exit codes, and the input-script and option-profile formats change only
in compatible ways. `docs/USING.md` has the full list. `STATUS.md` in the repository says what works and what does not.

Unofficial: not affiliated with or endorsed by the Azahar project. Nintendo and its trademarks belong to their owners;
this project is not affiliated with Nintendo.

## What is new in the 1.0 API

- Run options are keyword-only.
- `run_until` takes `stop_every` and `stop_new`.
- Calls that make files return `Path` objects.
- The option-profile and input-script formats are strict: a bad line is an error.
- New exit code 9 for `azhost`.
- The tick seed, `citra_init_ticks_override`, on our core.
- `threads()` lists the guest threads on our core.
- Reading the depth-stencil buffer works on MoltenVK.
- Restoring a saved state no longer crashes an app's first 3D draw on our core. The bug is in Azahar itself, and the stock core has it too.

## Assets

- `azahar_lazpy_libretro-2126.2-lazpy.2-macos-arm64.zip`: our core (Azahar 2126.2 plus our patches), with `NOTICES.md`, `LICENSE`, `COPYING-azahar.txt`, `SOURCE.md` and `build.inputs`.
- `azahar-unified-source-2126.2-lazpy-nokeys.tar.xz`: the Azahar source the core was built from (Azahar's tarball minus the files listed in `SOURCE.md`).
- `openssl-3.6.5.tar.gz`: OpenSSL's source tarball (the core links OpenSSL statically).
- `citra_system_archives-f470e0c.tar.gz`: a snapshot of the generator behind the system archives compiled into the core.
- `libazahar-py-core-build-v1.0.0.tar.gz`: the patches, pins, options and build script.
- `testapp.3dsx`: the small homebrew test app used by the tests.
- `NOTICES.md`, `SOURCE.md`: licence notices and source offer, also as plain files.
- `SHA256SUMS`: sha256 of every other asset.

## Requirements

Requires macOS 15 or later on Apple silicon (the statically linked OpenSSL is built for macOS 15). Python 3.10 or
newer (tested on 3.14 here; CI runs 3.10).

## Licence and source

The core binary is GPLv3; its complete corresponding source is on this page: the Azahar source asset, the OpenSSL
source tarball, the system-archive generator snapshot, the build files, and this repository at the tag.

## Homebrew only

Homebrew only: no ROMs, no console keys, no Nintendo certificates and no Nintendo system files are included or needed by the tests; our core is built
without Azahar's built-in key data and default HTTP client certificate, and it loads no keys.
