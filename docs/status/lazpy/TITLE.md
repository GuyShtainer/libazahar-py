# libazahar-py

A headless, scriptable host for the Azahar 3DS emulator's libretro core, plus a Python layer: no window, many copies
at once, buttons and touch, screenshots, guest memory. Public GPLv3 repo, always publish-ready. The plan is
`docs/` (PLAN.md), not written yet. Hours are logged in `docs/hours.tsv`.
