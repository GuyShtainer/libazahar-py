libazahar-py test app: a small 3DS homebrew (`build/testapp.3dsx`) that draws exact corner markers, logs one line per frame to `sdmc:/testapp/log.txt`, and obeys `sdmc:/testapp/control.txt`.
Licence: GPLv3 or later (our own code, glyphs and shader; nothing copied from the devkitPro examples).
Build: `PATH=/opt/devkitpro/devkitARM/bin:/opt/devkitpro/tools/bin:$PATH make -C testapp` (output `../build/testapp.3dsx`).
Stencil self-test: `stencil=N` in control.txt (N = 1..4) skips the normal loop. It fills a 128 x 128 depth+stencil (D24S8) target, draws one 100 x 80 quad that writes stencil 0x80, copies the depth buffer back with a GX TextureCopy and logs one `stencil v=<a|b|d> n80=... n00=... nff=... nother=... bbox=x0,y0,x1,y1 dq=... dbad=...` line per readback (a = first use, d = second readback in the same process, b = a dummy draw first). N: 1 = a then d, 2 = b, 3 and 4 = the same with an EQUAL/INCR stencil test (counts `n01`). Good result: `n80=8000 n00=8384 nff=0 nother=0 bbox=10,20,109,99 dq=8000 dbad=0`. Driven by `tests/python/test_stencil_live.py`.
